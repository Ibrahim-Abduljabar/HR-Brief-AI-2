# HR Brief AI — Internal Version

HR Brief AI is a Streamlit-based internal system that summarizes long HR reports (10–30 pages) into a clean executive brief within seconds.  
It extracts key points, analyzes numbers, identifies issues, and generates actionable recommendations.

---

## Features
- Full HR report summarization in seconds
- Key point extraction
- Number and table analysis
- Issue detection
- Actionable recommendations
- Half‑page executive summary
- Fast and clean English interface

---

## How It Works
1. Upload the HR report  
2. NLP models read and analyze the full content  
3. Key insights are extracted  
4. Numbers and issues are processed  
5. A ready executive brief is generated

---

## Tech Stack
- Python  
- Streamlit  
- Groq API  
- Advanced text processing
